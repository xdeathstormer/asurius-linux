# ASURIUS
Asurius is an in-development alternative to MyASUS and Armoury Crate for Linux. It uses backend tools like supergfxctl, asusctl, dmidecode and others for the tasks and unifies them into a single control panel.

Asurius uses C, and bash for the CLI and plans to use GTK4 (with CSS and C) for the GUI 

## As of 29/07/2026 Asurius is in development and is not a usable control panel. Its features are currently limited to basic functionality, and it does not have a GUI panel yet.
